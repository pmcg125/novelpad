> 2026-11-23 三次修正：不是三次葬礼，而是 N 次；方舟由她落足过的宇宙与记忆碎片整理、拼凑、编织而成。2073 与天穹同代；寒渊科技是独立公司，已被日亩农业低调整体收购，雾凇区在极昼／极夜无人区。

## 关键区分：启航 ≠ 结束

- **方舟启航**：旧宇宙毁灭后，残念收集碎片造出「旧梦残章」，带着残序和船员出发。
- **方舟航行期间**：她可以登陆、度假、卧底、探亲多个世界；天穹、2073、杖与结界、双界魔王都可以发生在这个阶段。
- **方舟结束**：使命完成，`exit code 0`，船员与文明散去。
- **旧梦残章之后**：结束后的退休日常，公寓、布丁、残序、只拥有现在 1 秒。

## 2073 与天穹：同一世界的上下两层

- **同一世界**：天穹在轨道上承载热数据、网络、主服务和上层文明；地面／地下是冷备份与灾备层。
- **2073 的位置**：永恒凛冬是这一层的时间／环境标记；寒渊科技的雾凇核心区是冷备份数据库，冬至是它的看守人。
- **为什么不在天穹上**：冷备份故意与天穹物理隔离，避免单点故障；天穹出事时，地面冷备份是最后的火种。
- **不是独立宇宙**：2073 不是方舟前的独立世界；它与天穹**同代**，只是 2073 里天穹不是主角设定。
- **寒渊科技**：独立公司，已被日亩农业低调整体收购；这条存在感很低，正文不必强调。
- **不是秘密项目**：雾凇区位于极昼／极夜地区的偏远无人区，没啥人找得到；项目不招摇、不公开，但不是国家秘密，冬至甚至能带残念进入核心机房。核心架构与数据内容仍属商业保密。
- **核心业务**：大量冷备份数据，同时有 GPU／CPU 超算与储备算力供应；冷数据内容较杂，具体构成待定。
- **雾凇区的天空**：上空的铁云／天穹分布不算多，通常以肉眼可见的速度缓慢掠过；这里不是被铁云完全覆盖的永夜区，而是极寒地面上的稀疏轨道设施。
- 用户 2026-11-23 补充：2073 与天穹同代，不是早期／晚期关系。

## 天穹的“前舰长”怎么解释

- 公开身份／传说：前舰长。
- 实际情况可以是：
  1. 她把指挥权临时交给 AI 或大副，自己下船度假；“前”是相对指挥权，不是相对方舟是否存在【天穹 204】。
  2. 她确实卸任了船长，但仍拥有方舟／仍是船主；天穹只是她的一站。
  3. 天穹本地人只知道“前舰长”这个传说，不知道她的船还在航行。
- 三种都不影响“天穹在方舟启航之后”这个硬条件。

## 冬至的方舟记忆

- 航行版推荐：方舟停靠 2073 期间，冬至曾登舰做客／短期驻留／协助维护，所以她的记忆是真实的；她不是长期船员，之后回 2073 继续看守数据中心。
- 这样她 2057 年出生、2073 年 16 岁，与“曾在方舟上”可以同时成立。
- 备选：胚胎／意识种子、方舟内部时间膨胀、低温休眠、灵魂回声。
- 未选定前，正文只写“她对那艘船有说不清的熟悉感”最安全。

## N 个被毁宇宙怎么处理

- 不是三次，而是 **N 次**：残念经历的可不止三次葬礼；她把曾经落足过的宇宙、记忆碎片整理、拼凑、编织，才形成方舟。那些宇宙大多没有在故事里点名。
- 故事里提到的“三个”只是样本，不是总数；不强制把杖与结界／双界魔王写成被毁宇宙。
- 如果想让某个故事世界带末日重量，可以把杖界／双界作为 N 次中的样本之一；但不要把它当成唯一的三次。
- 天穹／2073 仍然不能放回方舟前：它们有方舟启航之后的身份。

## 备选版 B：方舟结束后的播种

- N 个背景宇宙毁灭 → 方舟结束 → 天穹／2073、旧梦残章之后等新世界。
- 天穹／2073 是方舟结束后的新世界；冬至需要胚胎／种子、时间膨胀或灵魂回声机制。
- 适合“方舟已经没了，所有故事都发生在它留下的世界里”的写法；和航行版二选一。

## 残念的主观年表不是这条线

- 她只拥有“现在 1 秒”，没有属于自己的过去与未来（详见 [OC/残念.md](../OC/残念.md) 的 2.4）。
- 宇宙年表是客观顺序；她的主观记忆是分片和非线性的。不要用宇宙年表倒推她“此刻应该记得什么”。
- “学生”“前舰长”“魔王”“闺蜜”可以是她在不同停靠站留下的身份切片，不必严格服从宇宙年表的先后。

## 最终落点

- 方舟不是失败，是 `exit code 0`：进程正常结束，不是崩溃。
- 她不会恢复任何东西；她只保留现在 1 秒。
- “永恒不是最有价值的东西，而是珍惜有限。”
- “旧梦残章之后”不是续集，是 N 次葬礼之后的一顿布丁。
