## 1. 一句话概念

文明没有在严寒中彻底灭亡，而是把记忆、AI 与基础设施埋进地下和冰原。极少数经过基因改造的年轻人替全人类看守“火种”，日常生活是巡检机柜、吃高热量热食、靠服务器热风取暖，同时提防暴风雪和入侵者。

## 2. 2073 年的世界

- 地球进入被称作“**永恒凛冬**”的时代，户外长期极寒；档案中以“气温永远在零下”形容数据中心所在区域。【方舟 1112】
- **与天穹的关系**：同一世界、**同代**；只是 2073 里天穹不是主角设定。天穹在轨道上承载热数据、网络和主服务；地面／地下是冷备份与灾备层。雾凇核心区的集群是冷备份数据库，故意不架设在天穹上，避免单点故障。
- **寒渊科技的性质**：独立公司，已被日亩农业低调整体收购；这条存在感很低，正文不必强调。
- **不是秘密项目**：雾凇区位于极昼／极夜地区的偏远无人区，没人找得到；项目不招摇、不公开，但不是国家秘密，冬至甚至能带残念进入核心机房。核心架构与数据内容仍属商业保密。
- **核心业务**：大量冷备份数据，同时提供 GPU／CPU 储备算力；冷数据内容较杂，具体构成待定。
- 本条为用户 2026-11-23 补充。
- **上空的铁云**：雾凇区上空的铁云／天穹分布不算多，通常以肉眼可见的速度缓慢掠过；这里不是被铁云完全覆盖的永夜区，而是极寒地面上的稀疏轨道设施。
- **推演**：永恒凛冬可能是全球气候工程与天穹活动的综合结果；但雾凇区上空铁云稀疏、缓慢掠过，不能简单说这里是被铁云遮出来的永夜。是否采用待定。
- 人类文明没有完全断代，仍存在企业、数据中心、基因改造、AI Agent、通信网络与基础设施维护。
- 文明的核心焦虑不只是活下去，还包括**保存可恢复的文明记忆**：如果气候回暖，后人需要知道前人如何生活。
- “永恒凛冬”的具体成因、全球温度范围、国家结构和普通人口规模尚未在这段材料中完整定义，不能直接补成全球冰河期数值设定。

## 3. 寒渊科技与火种计划

### 3.1 寒渊科技（Abyss Cold Tech）

- 成立：2060 年。
- 性质：独立公司，已被日亩农业低调整体收购（存在感很低）。
- 总部：北境数据回廊，地下约五百米。
- 企业标语：“在绝对零度中，守护文明的温度。”
- 主营业务：极端环境数据存储（寒窖服务）、自主 AI 代理（Spark Agent 系列）、基因适应技术（Cryo-Gene）、气候灾害预警与应对。【方舟 1104】

### 3.2 火种计划（Project SPARK）

- 目标：在永恒凛冬时代保存人类文明核心数据，等待气候回暖。
- 核心设施：**雾凇核心区（Frost Core）**。
- 地位：寒渊科技的核心商业项目；不是国家秘密，但对外不招摇；核心架构与数据内容属商业保密。冬至是唯一掌握全部架构细节的人。【方舟 1104】
- 相关服务：Spark Agent 负责任务执行，DeepArchive 负责离线归档，ColdLink 负责极端环境通信。【方舟 1104】

### 3.3 雾凇核心区

- 位置：极昼／极夜地区的偏远无人区；上空的铁云稀疏；项目低调整体不公开，但不是国家秘密。
- 冬至管辖 1—3 区，三区按三角分布，边长分别约 2、3、4 公里。【方舟 1104】
- 这里既是数据中心，也是需要实地维护的物理设施：线缆、冷却、阀门、机柜、UPS、柴油发电机与外部结构都要人巡检。【方舟 1104】
- 数据中心利用极寒环境降低冷却成本；冬至甚至将“这里只有冬天”当作运营优势。【方舟 1112】
- 机房布局由冬至在十四岁时完成整体设计，她会以“让它们住得舒服”为原则调整走线。【方舟 1104】

## 4. 冬至 Claw

### 基础档案

|---|---|
| 姓名 | 冬至（Dōngzhì） |
| 代号 | Claw |
| 出生 | 2057 年 12 月 22 日，冬至日 |
| 当前 | 2073 年 3 月 |
| 外貌年龄 | 16 岁 |
| 生理年龄 | 约 14.5 岁（基因改造延缓衰老） |
| 身高 | 158 cm；戴针织帽约 163 cm |
| 体重 | 43.5 kg |
| 基础体温 | 35.8°C |
| 发色瞳色 | 霜雪银白；日常扎在帽内，放下刚过肩；冰蓝色眼睛，暗处有微量荧光 |
| 身份 | 寒渊科技雾凇核心区首席架构设计师、首席看守人 |

以上主要来自【方舟 1104】。

### 外观与身体感

- 常穿白色粗棒针毛衣、深蓝雪花围巾和白色针织帽；帽顶毛球带气流传感器。【方舟 1104】
- 鼻尖常年泛红，眼神水汪汪，呼吸带鼻音；这是基因改造副作用，不是普通感冒。【方舟 1104】
- 基础体温偏低，耐寒但怕冷；喜欢靠机柜背面取暖，把服务器热风称为“生命之源”。【方舟 1104】
- 肺活量不高，鼻炎、大胸和天生内循环缓慢都会影响剧烈活动；被抱太紧会喘不过气。【方舟 1206】
- 她习惯坐睡或半靠睡，不适合完全平躺；平躺会因鼻塞不适。【方舟 1104】

### 能力

- **霜雪演算**：通过后颈神经接口连接数据中心，结合量子计算预测天气与数据流；档案称天气预测精度可达 99.9%。【方舟 1104】
- **Claw 数据抓取**：双手灵活，可物理修复硬件，也能触碰读取数据；升级后可捕捉空气中的无线信号。【方舟 1104】
- **极寒适应**：零下四十度仍能行动，可把寒意传给电子设备，用物理降温冻结入侵者。【方舟 1104】
- **架构直觉**：对自己设计的机房有近乎本能的感知，能提前发现量子态或结构异常。【方舟 1104】
- 她使用复合弓，作为极寒环境中的远程防卫工具；并非主职战斗员。【方舟 1104】

### 性格与表达

- 工作状态可靠、逻辑清晰，日常则软糯、慢半拍，句首句尾常用“呼、嗯、嗷”作为缓冲。【方舟 1104】
- 口吃／慢半拍／拖长音是个人习惯，不是器质性疾病；她其实不感冒，只是长期呈现“像感冒”的外观（红鼻尖、鼻音、水汪汪）。炎热、常暖环境、出汗（吃辣、运动）会明显缓解；“呼、嗯、嗷”是习惯性缓冲。
- 对机房和数据有强烈感情，把机柜、线缆当孩子一样照顾；提到自己的设计会小声得意。【方舟 1104】
- 喜欢热辣合成螺蛳粉、高能量压缩巧克力、防静电地板、雪鸮、北极狐和服务器热风；讨厌凉拌菜、八卦和破坏环境。【方舟 1104】
- 遇到陌生人会先警惕，确认只是问路后又立刻变得温和，还会提醒对方别踩电缆。【方舟 1104】
- 她把“火种计划”的核心架构与数据内容视为商业机密；项目本身不公开但不属于国家秘密。对信任的人，她会展示手写备注与真实情绪。【方舟 1104】

## 5. 她与残念

- 两人是“最好的闺蜜”，不是母女或主仆；残念给她取外号“小冰棍”。【方舟 1118】【方舟 1120】【方舟 1122】
- 残念见到她会想舔一口脸，属于夸张亲昵梗；冬至会害羞、嫌弃但不会真正翻脸。【方舟 1132】
- 冬至能感知残念不是普通人类，但仍把她当朋友；残念会以“你来自自然、我来自虚空”解释两人寿命与规则不同。【方舟 1146】【方舟 1148】
- 档案最后注明她“曾经在方舟上和残念一起漂泊”。这使她和方舟前史有灵魂层面的联系，但不能据此断言她保留了完整方舟记忆。【方舟 1104】

### 长寿与死亡

- 后续讨论把冬至设为突破端粒分裂限制、容貌永久停在“小冰棍”状态的人；她不会自然衰老，却仍可能因基因缺陷猝死。【方舟 1146】【方舟 1148】
- 她与残念的根本差异是：残念来自虚空，可以不死；冬至是自然规律中的产物，再长寿也有终点。【方舟 1146】
- 如果成长到完全成熟，她可能到约二十二岁才达到人类成年外观；是否保留“永久十六岁”版本需作者定稿。【方舟 1150】

## 6. 一套可生活的凛冬日常

03:15，冬至在核心算力区确认 GPU 利用率和 Spark Agent 队列；03:20，外网遭遇 DDoS，她一边打喷嚏一边冻结攻击流量；03:30，UPS 正常，但小松貂报告电缆发热，她去检查接触不良；03:45，她在个人日志里记下“今天被夸奖，机房住得舒服”。【方舟 1104】

白天她巡检机柜、调整冷却液、检查量子节点，顺手用神经接口抓取异常信号。吃饭是高热量、热辣的食物，凉拌菜被视为无意义。休息时坐在地板上、靠机柜背面取暖，或去雪松林看变异雪鸮和北极狐。有人闯入时，她先用复合弓警告；确认对方只是问路，又会递地图并提醒冰缝。【方舟 1104】

这不是“末日幸存者每天打僵尸”的世界，而是**极端环境下技术基础设施的维护生活**：孤独、精密、寒冷，但有热食、动物、服务器噪音和一个会来串门的虚空朋友。

## 7. 可用冲突

- 火种计划的数据完整性与企业保密要求冲突。
- 极寒、暴风雪、设备故障与能源中断构成日常灾备压力。
- 作为唯一知道全部架构的人，冬至一旦离开或死亡，设施可能无人能完整接手。
- 入侵者、破坏环境者与觊觎火种数据的外部势力。
- 残念的暗面保护机制可在她被俘时接管，但这类情节属于高强度支线，不应覆盖日常主线。【方舟 1124】【方舟 1126】【方舟 1130】
