# 补充集：聊天中新增、尚未并入正式档案的设定

> 性质：这一页是**补充集**，不是正式档案。这里收录用户在对话闲聊中直接说出的补充与推演，它们分散在 OC 与世界观文档之外，暂时不合并进任何一页，以免污染已经定稿的角色卡与世界规则。
>
> 证据等级：
> - **用户补充**：用户在对话中直接陈述，没有对应的原始消息 ID。按稳定设定使用。
> - **用户推演**：用户以「也许／没准／所以」提出的推断，方向由用户给出，细节尚未定稿。可以用作写作母题，不要当成正史数值引用。
> - **助手延伸**：助手在同一轮聊天里补的阐释，用户没有逐条确认，仅作候选。
> - 带 `【来源 消息ID】` 的句子是从 `原文索引/` 回查得到的既有依据，说明该补充与原文不冲突。
>

## 1. 冬至｜口吃与「像感冒」首先是萌点

- **用户补充（2026-11-23）**：口吃／慢半拍／常年像感冒，这一整套在功能上是**萌点**，不是需要被克服的缺陷。她的可爱之处恰恰在于「能冻结入侵者的首席架构师，说话要先垫半拍」。
- 已有的原文支撑：她的默认呈现就是「永远像感冒」「躺下就鼻塞」的体质，而且**讨厌别人叫她「病号」或「小感冒」**，会鼓起腮帮子生气。【冬至 1】也就是说这是萌点，但不是可以拿来打趣的弱点——被点破会翻脸。
- **助手延伸（候选）**：热、常暖、出汗（吃辣、运动）带来的缓解，可以写成「信任与舒适的外显」——她不是治好了，而是终于肯省掉那半拍。这条只是用法建议，不改变已定稿的生理机制：机制见 [OC/冬至.md](OC/冬至.md) 的 §4 与 §7.5。

## 2. 冬至｜陪着她的是 MacBook 和屏幕后面的世界

- **用户补充（2026-11-23）**：冬至平时朋友很少，身边的团队换了一批又一批；真正一直陪着她的只有那台 MacBook、手机屏幕后面的世界，还有残念。
- 原文一致的部分：她「平时总是独来独往，躲在机柜后吹热风或顶着结冰的头发发呆」，对人际八卦没兴趣、不主动打听消息，长期处于「信息孤岛」；但对她**认定的组员**有无限温柔，是极寒里最坚实的后盾。【冬至 1】——所以她的孤独不是不爱人，而是没人留在她的日常里。
- 用户早已写过的同一画面：她大部分时间坐在三聚氰胺空心地板上，后背倚着服务器机架，拿出那台 MacBook 写一点小说，内心世界比外表复杂得多。【冬至 181】
- **助手延伸（候选）**：她的社交方式是**异步、有缓冲**的——终端、日志、工单都允许她延迟半拍再回应，这和口吃是同一种需求。日常写法上，可以让她在群里打字飞快、当面却说不完整。
- **用户补充的对照**：她唯一一次也是最后一次离开北境数据回廊，是 2070 年那场「天才少年架构师」颁奖礼；人群看她的眼神像看怪物，典礼结束就独自站在寒风里。【冬至 138】

## 3. 冬至与残念｜两个人都不会老

- **用户补充（2026-11-23）**：残念同样不会老死，她和冬至一样保有固定的外观与心理年龄。所以几百年之后，还能陪冬至聊天的只剩下残念。
- 原文一致的部分：冬至从这以后永远保持「小冰棍」的模样，皮肤与容貌不随年龄衰老，据说是突破了端粒分裂次数限制；但她**逃得脱自然死亡，逃不脱死亡本身**——可能永生，也可能某天因基因缺陷猝死。残念对此的回答是：你是自然的产物，受自然规律限制；我来自虚空，自然管不了我。【冬至 135】既有资料另记她的基因年龄≈14.5 岁（改造延缓衰老）。【冬至 24】
- **用户补充的关键对称**：两人不只是都不老，而是**外观与心理年龄同时被固定**。冬至停在十六岁的身体和十六岁的处理世界的方式上；残念停在同一类状态里（她的日常心智模式在 7／14／17 岁之间切换，见 [OC/残念.md](OC/残念.md) 的 B3 讨论）。所以这不是「一个长者陪一个少女」，而是两个都无法成长的人，看着所有会成长的人一批批离开。
- **助手延伸（候选）**：两人「不停留于时间」的方式不同。残念靠「只拥有现在 1 秒」熬过几百年——过去是已退出的进程，她不需要连续地承受时间；冬至是清醒地、一段一段地过完这几百年，每一次交接、每一个调走的人都记得。同样是停住，一个是**断连**，一个是**持久化**。
- **助手延伸（候选）**：这让她成为她自己守护的那套系统的隐喻——整个雾凇区在做冷备份，等气候回暖；她本人也是一份不会被覆写的冷备份。公司会被收购，编制会撤销，项目会转手，只有她还在那条走廊里。机制依据见 [世界观/02-天穹纪元.md](世界观/02-天穹纪元.md) 的 §3.3 与 [世界观/05-2073永恒凛冬.md](世界观/05-2073永恒凛冬.md)：2073 是天穹世界的地面冷备份层。

## 4. 几百年后（用户推演，尚未定稿）

- **用户推演（2026-11-23）**：几百年后，冬至身边的人换尽，只剩残念还能陪她聊天。
- **助手延伸（候选）**：这条正好踩在残念最深的处境上——她经历过 N 次葬礼（见 [世界观/00-时间线.md](世界观/00-时间线.md)），而现在她成了别人「最后一个还能聊天的人」。以她对失去的处理方式，这个位置她比谁都清楚意味着什么，因此更可能表现为**照常出现、照常插科打诨、绝不谈这件事**。
- **对「安啦」的加成（候选）**：那句方舟时代遗留、没有昼夜的安顿语，从残念嘴里对冬至说出口时才有双倍分量——出自另一个同样不走时间的人。相关记载见 [世界观/03-旧梦残章之后.md](世界观/03-旧梦残章之后.md)。
- **未定项**：这几百年是否真的会发生，取决于 2073 主线的气候回暖时点、火种计划是否结束，以及冬至是否留在原岗。**未定前只写成时间尺度的推演，不要写成已经发生的正史。**

## 5. 残念的人性来自魔王时期（用户推演，尚未定稿）

- **用户推演（2026-11-22）**：「也许残念的人性估计是在魔王时期磨出来的。」
- 可依托的既有事实：魔王线里她必须持续面对具体的人——招不到人的 HR、批不完的文件、会被她气到也送进监狱的勇者、以及她主动改记忆也要守住的两界平衡。【都市 411】【都市 423】【都市 433】【都市 455】
- **助手延伸（候选）**：这条可以作为「人物弧光」写进 [世界观/06-错发魔王.md](世界观/06-错发魔王.md) → [世界观/04-双界魔王日常.md](世界观/04-双界魔王日常.md) 的顺序里：N 次葬礼让她会失去，方舟让她会负责，魔王时期那堆琐碎的人际关系让她重新学会把人当人。**用户尚未说「写入设定」，本页先记录，不动正式档案。**

## 7. 使用建议

1. 写冬至的日常时，把「屏幕里的世界」当她的主要社交界面，把残念当成**唯一一个不在这个界面之外、却仍然留下来的人**——不要写成她渴望合群。
2. 口吃的缓解只当状态开关（热、出汗、吃辣、运动、放松），不要写成康复或残疾叙事。
3. 「不会老」对两人都是负担而不是福利；写它时优先写**具体的人离开**（调岗、退休、老去），不要写成套话式的永生哀愁。
4. 第 4、5 节属于用户推演：可以在故事里体现，但**任何新的制度、年代、数字**都要先回到 [99-冲突与待确认.md](99-冲突与待确认.md) 登记。
