# 配角与非核心角色索引

只收录在四份对话里出现姓名、独立身份或持续作用的角色。  
状态说明：

- **稳定**：用户直接创建或长期沿用。
- **故事角色**：用户设定并用于某条故事线，但不一定跨世界。
- **候选**：助手提出，用户没有明确采纳。
- **生物／道具**：不是人物 OC，但对生活线重要。

## 2. 《天穹纪元》

- 目标：让父亲以可读取的记忆体形式继续存在，并追查其死亡是否只是自动化事故。
- 性格／能力：不是黑客天才，更像被系统碾压后仍要行动的普通少年；他的力量来自家庭责任与对真相的执着。
