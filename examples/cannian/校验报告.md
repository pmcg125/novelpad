## 6. 复跑方式

在 `core` 目录运行：

```bash
python 设定提炼/工具/validate.py
```

脚本会重新计算 4 份 JSON 的统计、比对 `索引.json`、检查全部引用 ID 与内部链接；出现缺失引用或失效链接时以非零状态退出。
