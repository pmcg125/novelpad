# NovelPad 设计语言

> 关键词：**宣纸 · 墨 · 青竹** —— 暖黄宣纸底、青绿点睛、护眼优先。
> 界面要像书房里的稿纸：文字在前，工具退后。作家每天盯着它八小时，视觉负担越低越好。

---

## 1. 设计原则

| 原则 | 含义 | 落地方式 |
|---|---|---|
| **纸感** | 编辑区是稿纸，不是终端 | 暖色中性底、衬线正文、行高 2.0、段间留白 |
| **退让** | 视觉重心永远在正文 | UI 饱和度低、1px 细分割线、图标克制、无重阴影 |
| **护眼** | 长时间使用不疲劳 | 暖黄底（非纯白）、深色非纯黑、对比适中（正文 ≥ 7:1，次要 ≥ 4.5:1） |
| **一色一事** | 每种颜色只表达一种含义 | 青 = 当前 / AI；赭 = 待办；红 = 错误；绿 = 通过 |
| **可主题化** | 所有颜色走令牌 | Webview 只引用 `--vscode-*` 变量，自动跟随主题 |

| `bg.status` | `#E8E2D4` | `#171614` | 状态栏 |

| `bg.input` | `#FBF8F0` | `#26241F` | 输入框 |

> 决策记录：朱砂不再做品牌主色（用户选择青绿 + 宣纸暖黄，护眼优先），仅保留为错误色。
> 青色同时承担「激活态」和「AI」两个角色，二者不会同时出现在同一位置产生歧义（激活态在导航，AI 在编辑区 / 助手面板）。

### 2.2 图谱分类色

| 实体 | 浅色 | 深色 |
|---|---|---|
| 角色 | `#C8402F` | `#E5695A` |
| 地点 | `#B7791F` | `#D9A04A` |
| 势力 | `#3A6EA5` | `#7AA9DA` |
| 物品 | `#3C8C5A` | `#5DBA82` |
| 事件 | `#7C5CBF` | `#A48BE0` |

### 2.3 对比度要求

- 正文 / 编辑区底 ≥ 7:1
- UI 文字 / 侧栏底 ≥ 4.5:1
- 次要文字 ≥ 4.5:1；`faint` 仅用于占位符和禁用态，允许低于 4.5:1

## 3. 字体

### 3.1 字体栈

| 角色 | 字体栈 | 说明 |
|---|---|---|
| **系统 UI** | `"HarmonyOS Sans SC", "HarmonyOS Sans", system-ui, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` | 鸿蒙黑体优先，缺失则回退系统字体 |
| **正文 · 楷** | `"LXGW WenKai", "LXGW WenKai Screen", "Kaiti SC", "STKaiti", "KaiTi", serif` | 默认 |
| **正文 · 宋** | `"Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", "SimSun", serif` | 预设二 |
| **正文 · 黑** | `"Source Han Sans SC", "Noto Sans CJK SC", "PingFang SC", "Microsoft YaHei", sans-serif` | 预设三 |
| **等宽** | `"JetBrains Mono", "Cascadia Code", Consolas, monospace` | 仅 YAML / JSON / 代码块 |
| **数字** | `tabular-nums` | 字数、章节号、统计 |

> **授权**：霞鹜文楷（OFL）、思源宋 / 黑（OFL）、HarmonyOS Sans（华为免费商用授权）均可内置或引导安装。
> 鸿蒙黑体不随 OFL 发布，采取「检测到则使用，否则回退 system-ui」策略，不打包分发。

### 3.2 排版参数

| 元素 | 字号 | 行高 | 字距 | 备注 |
|---|---|---|---|---|
| 正文 | 19px | 2.0 | 0.02em | 段首缩进 2em（编辑区由渲染提供，源文件不存空格） |
| 章节标题 | 26px | 1.4 | 0 | 思源宋体 SemiBold |
| 卷标题 | 20px | 1.5 | 0.04em | 次级 |
| 侧栏项 | 13px | 1.6 | 0 | |
| 状态栏 | 12px | 1 | 0 | tabular-nums |
| Copilot 消息 | 14px | 1.8 | 0.01em | |

编辑区限宽 ≈ 36–40 汉字/行（约 760–840px），自动居中。

## 4. 布局

```
┌──┬────────────┬──────────────────────────────┬──────────────┐
│活│            │ 标签页                         │              │
│动│ 章节树      │                              │  Novel       │
│栏│ / 设定      │        编辑区（限宽居中）      │  Copilot     │
│  │ / 大纲      │                              │              │
│  │ / 图谱      │                              │  上下文卡     │
│  │            │                              │  消息流       │
│  │            │                              │  输入框       │
├──┴────────────┴──────────────────────────────┴──────────────┤
│ 状态栏：章节进度 · 视角 · 状态 · 诊断        字数 · 模型        │
└─────────────────────────────────────────────────────────────┘
```

- **活动栏**（48px）：章节 / 设定 / 大纲 / 图谱，底部设置 + 字数
- **主侧栏**（默认 260px）：当前视图容器内容
- **编辑区**：关行号、小地图、缩进线、折叠箭头；开段落间距、打字机滚动（可选）
- **辅助侧栏**（默认 300px）：固定给 Novel Copilot
- **状态栏**：左「章节 / 总章 · 视角 · 稿件状态 · 诊断摘要」，右「字数 · 目标进度 · Copilot 模型」
- **隐藏**：终端、运行调试、测试、源控制菜单中的开发者向条目（源控制保留，重新命名为「版本」）

## 5. 组件规范

### 5.1 章节树
- 卷：小字、`fg.muted`、可折叠；章节：13px
- 激活项：`bg.active` 底 + 左侧 2px `accent` 竖条
- 状态点（右缘 6px）：草稿 `warning` / 定稿 `success` / 有诊断 `error`
- 悬停显示 `+` / `…` 操作

### 5.2 角色卡（自定义编辑器）
两栏：左侧表单（名称、别称、标签、属性、关系），右侧实时预览（YAML 源码可切换）。
关系字段用「芯片」展示，点击跳转到对方角色卡。

### 5.3 Ghost Text（AI 续写）
- 颜色：`accent`，透明度 0.75；楷体与正文一致
- 120ms 淡入；浮动提示「Tab 接受 · Esc 忽略」（`fg.muted`，10px）
- 接受后不可区分，无残留高亮

### 5.4 诊断
- 波浪线：错误 `error` / 警告 `warning` / 提示 `accent`
- 悬浮卡片：标题 + 说明 + 「修复」「忽略此规则」按钮
- 灯泡菜单：润色 / 扩写 / 缩写 / 换视角（青色图标区分于普通代码操作）

### 5.5 图谱（Webview）
- 背景 = `bg.editor`，网格关闭
- 节点：圆形，分类色描边 2px，填充为分类色 15% 透明；选中态外圈 `accent`
- 边：`fg.muted` 40%，1px；因果边虚线；hover 时高亮为 `accent`
- 标签：12px 系统字体；节点 > 80 个时仅 hover 显示
- 左上角筛选器：章节范围滑块、实体类型复选

### 5.6 Copilot 面板
- 头部：青色圆形图标 + 「Novel Copilot」
- 上下文卡：`bg.input` 底，`border` 边，13px，展示本章角色 / 地点 / 最近事件
- 助手消息：`accent.soft` 底，圆角 8px，左侧 2px `accent`
- 用户消息：`bg.hover` 底，右对齐
- 引用来源（RAG 命中）折叠显示为「依据：第 3 章 · 第 12 章」，点击跳转

### 5.7 按钮
- 主按钮：`accent` 底 + `accent.fg` 字，高 28px，圆角 4px
- 次按钮：透明底 + `border` 边 + `fg.ui` 字
- 幽灵按钮：无边框，hover 显示 `bg.hover`
- 禁用：`fg.faint`，opacity 0.6

## 6. 图标与品牌

- **产品图标**：Lucide（线性，1.5px 描边，ISC 协议）；AI 相关操作图标统一青色
- **文件图标**：按类型着色——章节 `fg.ui` / 角色 `accent` / 世界观 `info` / 大纲 `warning`
- **Logo**：圆形青竹印章 + 负空间「N」与笔尖；字标 NovelPad 用思源宋体
- **应用图标**：圆角方形，`accent` 底，白色负空间 N

|---|---|---|
| 悬停 / 按钮反馈 | 120ms | ease-out |

## 8. 令牌工程化

```
design/
└── tokens/
    ├── color.json          # 色彩令牌（唯一来源）
    ├── typography.json     # 字体与排版
    ├── spacing.json        # 间距 / 圆角 / 阴影
    └── build/              # Style Dictionary 输出
        ├── themes/novelpad-paper-color-theme.json
        ├── themes/novelpad-ink-color-theme.json
        └── webview/tokens.css    # --vscode-* 变量映射
```

- `packages/theme`：由令牌构建出的 VS Code 主题 + 文件图标 + 产品图标主题
- Webview 只使用 `var(--vscode-*)`，不写死色值
- 每次修改令牌 → 跑 `pnpm build:tokens` → 三个产物同步更新

---

## 9. 与导出排版的关系

屏幕排版（楷体、宣纸底、2.0 行高）**只服务于写作过程**。
导出排版由导出 Profile 独立定义（宋体 / 黑体、印刷行距、页边距），二者解耦，互不影响。
